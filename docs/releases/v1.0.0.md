# Lancy v1.0.0 Release Notes

**Release Date:** August 19, 2026  
**Tagline:** "Where Talent Meets Opportunity"

## Release Highlights
Lancy v1.0.0 is the inaugural public open-source release of the full-stack freelancer marketplace platform.

### Key Capabilities
- **Marketplace Core**: Freelancer profiles, project listings, proposal submission, contract milestones.
- **Financial Architecture**: Minor-unit integer money math, double-entry `LedgerEntry` system, Stripe Mock payment provider with webhook idempotency.
- **Real-Time Communication**: Socket.IO authenticated channels for instant messaging and unread notification badges.
- **Trust & Moderation**: RBAC administration, project/review moderation, contract dispute resolution, and append-only `AuditLog` history.
- **Search & AI Intelligence**: PostgreSQL relevance ranking, Gemini/Mock AI provider abstraction, skill extraction, proposal drafting assistant, and candidate matching.
- **Production Hardening**: Request correlation IDs (`x-request-id`), standardized JSON exception filter, health/readiness probes (`/health`, `/ready`), multi-stage Docker containerization, and GitHub Actions CI.
