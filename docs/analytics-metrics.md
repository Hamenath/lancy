# Lancy Metric Definitions & Formulas

## 1. Proposal Acceptance Rate
$$\text{Acceptance Rate (\%)} = \frac{\text{Accepted Proposals}}{\text{Total Submitted Proposals}} \times 100$$

## 2. Project Fill Rate
$$\text{Fill Rate (\%)} = \frac{\text{Active Contracts} + \text{Completed Contracts}}{\text{Total Posted Projects}} \times 100$$

## 3. Contract Completion Rate
$$\text{Contract Completion Rate (\%)} = \frac{\text{Completed Contracts}}{\text{Total Started Contracts}} \times 100$$

## 4. Zero-Result Search Rate
$$\text{Zero-Result Search Rate (\%)} = \frac{\text{Searches Returning 0 Items}}{\text{Total Search Queries}} \times 100$$
